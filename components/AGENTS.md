# DOX -- components

**React UI components for GT-ASSIST-V2**

## Ownership

Each subdirectory owns its own domain:

- chat/ -- Chat Interface
- media/ -- Media Studio (image, video, animation generation)
- photoshop/ -- Photoshop Corner (in-browser image editor)

## Local Contracts

- All components are React functional components with TypeScript
- Components use Tailwind CSS for styling (dark theme, slate/green palette)
- State: useState/useCallback/useEffect for local state; context for global state
- No class components

## Child DOX Index

- chat/AGENTS.md -- Chat Interface
- media/AGENTS.md -- Media Studio
- photoshop/AGENTS.md -- Photoshop Corner
